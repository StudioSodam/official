# Studio Sodam Outsourcing Portal

스튜디오 소담 외주 회사를 위한 내부 관리용 웹 애플리케이션입니다. 클라이언트 관리, 커뮤니케이션 기록, 결제 및 프로젝트 상태를 한 화면에서 관리할 수 있도록 구성되었습니다.

## 주요 기능

- **로그인 및 프로필 관리**: 기본 관리자 계정과 세션 기반 인증, 비밀번호 변경 기능 지원.
- **클라이언트 관리**: 클라이언트 등록/수정, 상태(진행/보류) 필터링 및 상세 정보 확인.
- **프로젝트 추적**: 프로젝트 상태, 일정, 예산을 클라이언트별로 등록 및 확인.
- **결제 관리**: 인보이스 발행, 상태 변경(요청/송신/입금 완료)과 마감일 관리.
- **채팅 로그**: 담당자 간 커뮤니케이션 기록을 남기고 최신 메시지를 대시보드에서 확인.

## 로컬 실행 방법

1. 가상환경을 생성하고 필요한 패키지를 설치합니다.
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
2. 개발 서버를 실행합니다.
   ```bash
   flask --app app run --debug
   ```
3. 브라우저에서 `http://127.0.0.1:5000`에 접속합니다. 기본 계정은 `admin@studiosodam.com / sodam1234` 입니다.

최초 실행 시 SQLite 데이터베이스(`studio_sodam.db`)가 자동으로 생성됩니다.
